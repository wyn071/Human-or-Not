# Human or Not

**Human or Not** is a guessing game about spotting the difference between authentic (human-made) and AI-generated work.

Players are shown a series of text and image exhibits, then must decide whether each one was made by a human or generated by AI. After each guess, the game reveals the answer along with source details and context.

## Features

- Human vs AI guessing gameplay
- Text and image exhibits
- Easy, Medium, and Hard difficulty levels
- Standard and Timed modes
- Score tracking
- Reveal screen with verdict, source metadata, and notes
- Local image assets and metadata
- Newspaper-inspired visual style

## Gameplay

Each round presents an exhibit. The player chooses:

- **AI-Generated**
- **Human-Made**

For text entries, the guessing state shows the text, a neutral category-style desk note, and the exhibit title.

For image entries, the guessing state shows the image, a neutral description, and a scan-style artifact label. Source details are only shown after the player makes a guess.

## Image Dataset

Image entries are organized by origin and difficulty:

```text
Human or Not Images/
├── Authentic Images/
│   ├── Easy/
│   ├── Medium/
│   └── Hard/
├── AI Images/
│   ├── Easy/
│   ├── Medium/
│   └── Hard/
├── Authentic Image Notes/
└── AI Image Notes/
```

The Markdown note files contain metadata such as title, creator, model, equipment, date, source link, description, and person in photo when available.
